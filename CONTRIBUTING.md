# Contributing

This repository accepts one kind of contribution: a listing of an EigenMol
plugin, or a change to one.

- To list a plugin or a new version: [docs/REGISTERING_A_PLUGIN.md](docs/REGISTERING_A_PLUGIN.md).
- To report a problem with a listing: open an issue with the
  **A problem with a listed plugin** template. Do not attach your own
  structures, results or project files; this repository is public.
- A problem in a plugin's own code belongs with its publisher.

Every pull request is checked automatically and reviewed by a maintainer
before it is merged. See [docs/MAINTAINING.md](docs/MAINTAINING.md).
